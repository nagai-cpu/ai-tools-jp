Perplexityの入力データは学習される？法人が見る設定とEnterpriseの条件

2026-11-09 公開

この記事にはアフィリエイト広告（PR）を含みます。無料プランで実際に試した範囲の内容で、報酬額で順位を変えることはしていません。

結論から言うと、Perplexityの無料・Pro・Maxでは「AI data retention」が初期設定でオンになっていて、入力したデータがAIの学習に使われる状態です。設定でオフにできますが、止められるのはオフにした日以降の分だけです。Enterprise Pro と Enterprise Max のデータは、公式ヘルプで学習に使わないと明記されています。

判断軸1｜社員が個人アカウントで使っていないか

法人でいちばん起こりやすいのは、社員が個人の無料アカウントやProで業務の質問をしているケースです。公式ヘルプは、無料・Pro・MaxではAI data retentionが初期設定でオンになっていて、オンのままならデータが学習用に集められると書いています。

オフにする手順は、ヘルプによると次のとおりです。

  1. アカウント設定を開く
  2. 「Preferences」のページへ進む
  3. 「AI data retention」の切り替えを探す
  4. オンになっていれば、学習用にデータが集められている
  5. オフにして学習用の収集を止める

注意点が2つあります。1つは、オフにしてもそれ以前に集めた学習データは削除できないこと。もう1つは、この設定が利用者1人ずつにしか効かないことです。会社として「学習させない」を徹底したいなら、社員一人ひとりの設定に頼る形は管理しきれません。

また、オフにしても、サービスの運用、法令対応、製品改善のためにデータが処理される場合があるとヘルプは書いています。プライバシー通知も、データを使う目的の1つに「AIモデルを含むサービスや製品の改善・開発」を挙げています。

判断軸2｜Enterpriseにするなら、保持期間まで決められるか

Enterprise ProとEnterprise Maxについて、公式ヘルプは「データが学習に使われることはない」と書いています。料金ページのよくある質問でも、どちらのプランも顧客データをAIモデルの学習に使わないと説明しています。AIの提供元（OpenAI、Anthropicなど）とは、データを保持しない・学習させない契約を結んでいるとも書かれています。

ただし、保持期間を組織で決められるのは、Enterprise Proなら50席以上、またはEnterprise Maxが1席以上ある組織です。少人数でEnterprise Proを入れる場合は、アップロードしたファイルが7日間保持されるという既定の扱いになります。

もう1つ見落としやすいのが、契約を変えたときの扱いです。ヘルプは、Enterpriseから無料などのプランに切り替えると一般向けの方針に戻り、AI data retentionが初期設定でオンになるため、手動でオフにする必要があると書いています。

ほかの生成AIでの扱いは、ChatGPT Team・Enterpriseの音声は学習されない？やGeminiの文字起こしは学習に使われる？で整理しました。

判断軸3｜会議の録音や議事録を、どこで文字にしているか

Perplexityは調べものや資料作成に使われることが多いツールですが、会議の議事録を貼り付けて要約させる使い方もあります。このとき、Perplexity側を学習なしにしても、その前の段階で録音を文字にしたツールが学習に使う条件なら、守りたい情報はそこで外に出ています。

例えばNottaでは、利用規約に「ご利用のプランに応じて」音声を音声認識トレーニングに使う場合があると書かれています。法人向けページで「AI学習なし」が書かれているのは、ビジネス Plus（年64,800円・税抜）、エンタープライズ、士業向け特別プランです。

向くのは、Perplexityを学習なしの条件で入れたうえで、会議の録音から議事録までの流れも同じ条件に揃えたい法人です。録音を扱わないなら、まずPerplexity側の設定だけで足ります。

正直な短所

  • Perplexity（個人プラン）：学習の設定は初期値がオンで、オフにしても過去の学習データは消せません。ヘルプによると設定は利用者ごとに効くもので、会社がまとめて止める方法は個人プランの説明に見当たりませんでした
  • Perplexity（Enterprise）：保持期間を自分で決められるのは、Enterprise Proなら50席以上、またはEnterprise Maxを含む組織です。料金はドル建てです
  • Notta：Perplexityのような検索や調べものの機能はありません。「AI学習なし」はビジネス以下のプランに書かれていません
  • この記事の限界：実際の設定画面は確認していません。画面の名称は変わる可能性があります

よくある質問

Perplexity Proにすれば学習されませんか

されます。公式ヘルプでは、無料・Pro・MaxのいずれもAI data retentionが初期設定でオンです。学習に使わせたくなければ、アカウント設定のPreferencesで自分でオフにします。

過去に入力したデータも学習から外せますか

外せません。ヘルプは、オフにした効果はオフにした日以降に集めたデータにだけ及び、すでに集めた学習データは削除できないと書いています。

Enterpriseをやめたらどうなりますか

ヘルプによると、無料など一般向けのプランに切り替えると一般向けの方針に戻り、AI data retentionが初期設定でオンになります。切り替え後は、アカウント設定で手動でオフにする必要があります。

まとめ

  • 無料・Pro・MaxはAI data retentionが初期設定でオン。オフにしても過去の学習データは消えず、設定は利用者ごと
  • Enterprise ProとEnterprise Maxは学習に使わないと明記。保持期間を決められるのはEnterprise Pro 50席以上かEnterprise Maxを含む組織
