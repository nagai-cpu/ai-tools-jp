録音データの社外持ち出しルール｜私物スマホ・個人クラウド・外部AIの線引き

2026-10-31 公開

この記事にはアフィリエイト広告（PR）を含みます。無料プランで実際に試した範囲の内容で、報酬額で順位を変えることはしていません。

結論から言うと、録音データの持ち出しルールは「禁止の一文」より、持ち出し先ごとに「何を確認できないから止めるのか」を書き分けるほうが運用できます。私物スマホは紛失、個人クラウドは契約を会社が確かめられないこと、外部AIは学習に使われるかが論点です。そのうえで、録音を最初から会社のワークスペースに置き、共有リンクとダウンロードを権限で絞れるツールに寄せると、ルールを守る手間が減ります。

この記事で確認した一次資料

2026年10月31日に、e-Govの個人情報の保護に関する法律（第23条〜第25条・第28条）、個人情報保護委員会の「個人情報の保護に関する法律についてのガイドライン（通則編）」の別添「講ずべき安全管理措置の内容」、同委員会のQ&A（Q7-53・Q12-3）、「生成AIサービスの利用に関する注意喚起等」（令和5年6月2日）、Nottaの料金ページ・法人向けページ・利用規約・ヘルプセンターを確認しました。

従業員が個人のAIを使う問題全体はAI文字起こしのシャドーAI対策で扱ったので、この記事はすでにある録音ファイルを外へ持ち出す行為のルールに絞ります。

判断軸は3つ

1. 「持ち出し」を、媒体ではなく管理の手が届くかで定義する

個人情報保護法第23条は、個人データの漏えい等の防止のために必要かつ適切な措置を求め、第24条は従業者への監督を求めています。通則ガイドラインの別添は、物理的安全管理措置の10-5(3)で、個人データが記録された電子媒体等を持ち運ぶ場合、容易に個人データが判明しないよう安全な方策を講じなければならないとしています。中小規模事業者の手法の例としては、パスワードの設定などで紛失・盗難等を防ぐことが挙げられています。

法令が「私物スマホ禁止」と名指ししているわけではありません。そこで社内ルールでは、「会社が消せない・見えない・止められない場所に置くこと」を持ち出しと定義すると、USBも私物スマホも個人のクラウドも同じ物差しで扱えます。技術的安全管理措置10-6(1)の中小規模事業者の手法の例も、個人データを取り扱うことのできる機器と従業者を明確化するという書き方です。ルールには「録音を扱ってよい端末」と「扱ってよい人」を並べて書きます。

人的安全管理措置10-4は、秘密保持に関する事項を就業規則等に盛り込むことを手法の例に挙げています。退職者の録音の行き先はAI文字起こしの退職者アカウントとデータで整理しています。

2. 外部のAIに入れるなら、「学習」と「契約」を会社が確かめられるか

個人情報保護委員会の注意喚起は、個人情報取扱事業者が本人の同意なく個人データを含むプロンプトを生成AIサービスに入力し、それが応答結果の出力以外の目的で取り扱われる場合、法の規定に違反することとなる可能性があるとしています。そのため、提供する事業者が機械学習に利用しないこと等を十分に確認するよう求めています。

クラウドの扱いについて、委員会のQ&AのQ7-53は、判断の基準を「保存する電子データに個人データが含まれるか」ではなく、クラウドサービス提供事業者が個人データを取り扱うこととなっているかどうかだとしています。取り扱わない場合の例として、契約条項で取り扱わない旨が定められ、適切にアクセス制御を行っている場合が挙げられています。個人が自分で契約したサービスでは、この契約条項を会社が確かめる手段が乏しくなります。ルールで「会社が契約したサービスに限る」とする理由は、ここに置けます。

Nottaの場合、利用規約の第10条は、音声認識エンジンを提供するパートナー企業が「ご利用のプランに応じて」音声データを音声認識トレーニングに利用する場合があると書いています。AI学習なしはヘルプでエンタープライズとビジネス Plus、法人向けページで士業向け特別プランに挙げられており、標準のビジネスプランはヘルプの比較表で音声認識のAI学習が「あり」です。会社として許可するなら、この3つのどれかが候補になります。

3. 外国のサーバは「国名」で禁止せず、確認項目にする

法第28条は、外国にある第三者に個人データを提供する場合、原則として、あらかじめ外国にある第三者への提供を認める旨の本人の同意を求めています。一方でQ&AのQ12-3は、外国の事業者のサーバでも、サーバ運営者が個人データを取り扱わないこととなっている場合は提供に当たらないとし、その場合でも外国の制度等を把握したうえで安全管理措置を講じる必要があるとしています。通則ガイドライン別添の10-7（外的環境の把握）も同じ趣旨です。

ルールには「海外は禁止」と書くより、「保存国」「処理の送信先」「事業者が取り扱うか」を承認時に記録する欄を作るほうが、後から説明できます。Nottaのヘルプは、データの保管先をAmazon Web Servicesの東京のデータセンターとしています。要約など、保存とは別の処理の送信先の見方はAI文字起こしは海外サーバー？保存先と送信先の確認にまとめています。

Nottaの上位プランが選択肢になる条件

次の3つがそろう会社では、持ち出しを「禁止して見張る」より、Nottaのビジネス Plus（法人向けページで年64,800円・税抜）やエンタープライズに録音を集めるほうが、ルールと運用が一致しやすくなります。

  • 会議の録音に顧客名や人事の話など、個人データや機密が入る
  • 外部のAIでの文字起こしや要約を一律に禁止すると、業務が回らない
  • 社外への共有を、期限とパスワード付きのリンクに限りたい

ヘルプによると、ビジネス以上では作成したノートが初期設定で作成者のみのアクセスになり、ノートやフォルダに「閲覧のみ／編集可能／編集＆ダウンロード可能／フルアクセス」の権限を付けられます。ダウンロードできるのは「編集&ダウンロード可能」以上の人です。エンタープライズでは、個人用ワークスペースの新規作成の禁止と、ダウンロード履歴を含む操作ログ（過去180日）が使えます。

正直な短所

  • Notta（全プラン）：法人契約FAQに、多要素認証・2段階認証には「現在、対応しておりません」とあります。IPアドレス制限（ビジネスは20個まで）で補えますが、ヘルプは4G回線では使わないよう案内しています
  • Notta（共有リンク）：共有リンクはすべてのプランで、「編集可能」以上の権限を持つ人が作れます。モバイルアプリの説明では、リンクを知っている全員がログイン不要でアクセスできます。期限とパスワードは任意の設定です
  • Notta（ビジネス Plus）：ダウンロード履歴を含む操作ログと、個人用ワークスペースの作成禁止は、ヘルプではエンタープライズで利用可能とされています。ワークスペース全体でダウンロードを一括で止める設定は、今回見たヘルプでは確認できませんでした
  • ルール側の限界：ツールで止められるのは、会社のワークスペースに入った録音だけです。ICレコーダーなどで録った元のファイルは別に扱いを決めます

よくある質問

私物スマホでの録音は禁止しないといけませんか

通則ガイドラインの別添に、私物スマホを名指しした記述は確認できませんでした。求められているのは、持ち運ぶ電子媒体で個人データが容易に判明しないようにすることなどです。認めるなら、端末のロック、保存場所、退職時の削除を条件に書きます。

海外のAIサービスに録音を入れると、法第28条の違反になりますか

国名だけでは決まりません。Q&AのQ12-3は、外国の事業者のサーバでも、運営者が個人データを取り扱わないこととなっていれば提供に当たらないとしています。取り扱うこととなっている場合は第28条の検討が要ります。個別の判断は、社内の法務や専門家に確認してください。

Nottaの共有リンクは、社外の人がログインなしで見られますか

ヘルプのモバイルアプリの説明では、リンクを知っている全員がログイン不要でアクセスできます。有効期間とパスワード保護は設定でき、ビジネス以上ならオーナーが外部共有自体を無効にできます。

まとめ

  • 持ち出しは媒体で列挙せず、「会社が消せない・見えない・止められない場所に置くこと」と定義すると、私物スマホも個人クラウドも同じ物差しで扱える
  • 外部のAIは、学習に使わないことと契約条項を会社が確かめられるかで許可を分ける（個人情報保護委員会の注意喚起とQ&A Q7-53）
  • Nottaで受け皿を作るなら、AI学習なしのビジネス Plus・エンタープライズ・士業向け特別プランが候補。多要素認証は非対応で、ダウンロード履歴の操作ログはエンタープライズのみ
