AI記事作成ツール比較｜日本語6つの料金と無料枠を公式表記のまま並べた

2026-09-08 公開

この記事にはアフィリエイト広告（PR）を含みます。無料プランで実際に試した範囲の内容で、報酬額で順位を変えることはしていません。

結論から言うと、個人で自分のブログに使うなら月額1,000円未満から入れるツール、会社の予算で外注を置き換えるなら数万円のツールという分かれ方になります。日本語のAI記事作成ツールは同じカテゴリに見えて、月額840円のプランと月額10万円のプランが同居しています。金額を横に並べても選べないのは、そもそも数えている単位が違うからです。

名前が似ているだけの別サービスがある

先に混同を1つ外しておきます。表にある「Value AI Writer byGMO」（one.value-domain.com）と「AI Writer」（ai-writer.jp）は別のサービスです。後者のページに GMO や Value Domain との関係についての記載はなく、料金も前者のエントリーが月額840円、後者の個人プランが月額10,000円と桁が違います。レビュー記事がどちらの話をしているのか、URLを見ないと取り違えます。

「無料」に2種類あるのを最初に分ける

一覧を見て最初に切るべき線はここです。無料と書いてあっても中身が違います。

永久に0円で使える枠があるもの……Value AI Writer のフリー（月間1記事）、Catchy の Free（毎月10クレジット）、ラクリンのフリー（20,000トークン）。ラクリンは公式ページに「クレカ登録不要で永久無料」と書かれています。

期限付きのトライアルであるもの……Transcope の Free は「4,000文字」かつ「利用期限1週間」、SAKUBUN は「5日間の無料トライアルプラン」、AI Writer は「7日間無料トライアル」で「無料で5記事まで作成可能」。

つまり後者は、期限が切れたら有料プランに進むか使うのをやめるかの二択です。「無料で試してから決めたい」までは同じでも、「無料のまま細々と続けたい」なら候補は前者の3つに絞られます。ここを分けずに一覧表の「¥0」だけを見ると、1週間後に使えなくなるツールに時間を投資することになります。無料枠を続ける前提で数え直した話はブログ記事が書けない・続かない｜無料枠で何回やり直せるか数えたに書いています。

Value AI Writer のフリープランは月間1記事で、公式ページによれば「タイトル、見出しの生成までを1記事とみなします」というカウントです。少ないですが、期限で消えることはありません。

選ぶときの判断軸は3つ

1. 自分の使い方が「記事数」で数えられるか

月に何本という数え方が実態に合っているなら、記事数で課金されるツール（Value AI Writer、AI Writer、SAKUBUN）が素直です。逆に「1本を何度も書き直す」「記事以外に広告文やメール文面も作る」使い方だと、記事数の枠は実態に合いません。

Catchy は生成1回ごとにクレジットが減る方式で、公式ヘルプによれば「基本的に、1度文章を生成するごとに1クレジット消費する仕組み」です。長文を出すツールでは2〜4クレジット消費すると書かれています。数え方が細かいぶん、記事以外の短い文面を大量に作る使い方でも無駄が出ません。この単位の実感はCatchy無料クレジット10で何ができる？記事1本でほぼ使い切るにまとめました。

ラクリンと Transcope はトークン／文字数で数えます。「文字数で数える」は一見わかりやすいのですが、やり直した分も生成した文字数として積み上がる点は見落としがちです。Transcope の Basic は月50,000文字なので、1万字級の下書きを5回作り直したら1か月分になります。

2. 個人利用が想定されているか

これは料金よりも先に効きます。SAKUBUN の料金ページには「※ 原則、個人利用の方のトライアルは承っておりません。」と明記されています。プランもすべて「お問い合わせ」で、公開された定価がありません。個人ブログのために比較検討する対象からは外れるということです。

Transcope も Basic が月11,000円からで、公式ページには文字数追加や「情報学習量追加」「文字起こし時間追加」といったオプションが並びます。会社が業務として使う設計で、個人が趣味のブログに使うと無料枠のあとの着地が急に高くなります。

3. 高いプランでしか使えない機能が、自分に必要か

Value AI Writer は同じサービス内でプランによる機能差を公開しています。公式ページでは見出し構成の生成方式のうち「検索結果から選択してAIで構築」がプロプラン以上、「サジェストキーワード調査」がプロ・エキスパート限定、「被リンクドメイン調査」「競合サイト獲得キーワード調査」がエキスパート限定と書かれています。

一方で本文生成については「本文生成は GPT-4o,4.1・Claude4.0・Gemini2.5-Pro を全プランで選択できます」と書かれており、モデルの選択自体は安いプランでも制限されていません。文章を出すこと自体は下位プランでもでき、差がつくのは競合調査まわりという切り分けです。自分で調べる部分を持っているなら、下位プランで足ります。

正直な短所

  • Value AI Writer：フリーは月間1記事で、公式表記では「タイトル、見出しの生成をした時点で1記事とカウントされます」。構成を1回作り直すと、その月の枠が終わります。またSEOについて公式ページは、上位表示を約束できるものではない旨を明記しています。書けば上がる道具ではありません。
  • Catchy：Free はプロジェクト1つまでで、毎月10クレジット。記事1本を通しで作ると足りません。無制限に使いたい場合は Pro（¥9,800/月）まで上がります。
  • ラクリン：無料は20,000トークン・毎月約2記事の目安で、次のシルバーが¥4,980（税込）。無料と有料の間の刻みが大きく、「月に5本だけ」という中間の使い方に合うプランが公式ページの一覧には見当たりません。
  • Transcope：無料枠が4,000文字・利用期限1週間と短く、試している間に判断しきれない可能性があります。有料の下限も¥11,000です。
  • SAKUBUN：料金が全プラン「お問い合わせ」で、事前に予算を見積もれません。トライアルも原則として法人向けです。
  • AI Writer（ai-writer.jp）：個人プランが月10,000円で5記事。記事単価で見ると表の中では高い部類です。年払いなら月9,000円と書かれています。

文章の質そのものより、枠の切れ方で使えなくなるほうが実際には多く起こります。

よくある質問

Q. 無料のAI記事作成ツールだけでブログを続けられますか？ 続けられる可能性があるのは、永久無料の枠を持つ Value AI Writer フリー（月間1記事）、Catchy Free（毎月10クレジット）、ラクリン フリー（20,000トークン・毎月約2記事）の3つです。合わせても月に数本規模で、公開前の確認は自分で必要です。本数を出す運用には向きません。

Q. 日本語の精度はどれが一番高いですか？ 公式ページの記載だけでは比較できませんでした。Value AI Writer は「本文生成は GPT-4o,4.1・Claude4.0・Gemini2.5-Pro を全プランで選択できます」と使用モデルを公開していますが、他社は使用モデルや精度の数値を公式ページ上に同じ粒度では出していないため、横並びの比較になりません。精度の話をするなら、モデル名が公開されているかどうかを先に見るのが実際的です。

Q. AIが書いた記事はそのまま公開していいですか？ Value AI Writer の公式ページは「ベースとなるAIのコンテンツポリシーと利用規約に従っていれば商用利用可能」としています。同時にSEOについては、上位表示を約束できるものではないため「あらかじめご了承いただいた上でご利用ください」とも書かれています。生成物を確認せずに出す運用は想定されていません。広告文やコピーのように短い文面をAIで作るときの考え方はキャッチコピーをAIで無料作成｜商品名から出せる4つを実際に試したが近いです。

あわせて読む

  • Catchyの解約方法と、解約後もクレジットが残る条件｜返金は無い
  • AI記事作成の商用利用と著作権｜公式規約に書いてある注意点を読み比べた
  • 提案書作成をAIで時間短縮｜上限は月の生成枚数とやり直しの回数で決まる
  • 広告コピーが思いつかないのは1本しか考えていないから｜15枠を埋める順番
  • ブログ記事が書けない・続かない｜無料枠で何回やり直せるか数えた
