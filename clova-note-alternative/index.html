CLOVA Note終了の代わりは？無料で使える乗り換え先を比較

2026-08-16 公開

この記事にはアフィリエイト広告（PR）を含みます。無料プランで実際に試した範囲の内容で、報酬額で順位を変えることはしていません。

結論から言います。スマホやICレコーダーで録った音声を月300分以内で文字にしたいなら、後継の「LINE WORKS AiNote」フリープラン（0円）が一番近い代わりです。ZoomやTeamsの会議に同席させたい、AI要約まで無料で使いたいなら Notta の無料プラン。この2つで大半の乗り換えは片付きます。

そして、乗り換え先を調べるときに一番引っかかりやすい誤解を先に潰しておきます。

「後継は月2万円の法人向け」は正確ではない

CLOVA Note の終了後に書かれた記事の多くが、後継の LINE WORKS AiNote を「チーム 19,800円/月〜の法人向けサービス」として紹介しています。それ自体は間違いではないのですが、公式の料金表には、その下に個人向けの2プランがちゃんと載っています。

公式サイトの料金比較を確認したところ、個人向けは次の2つでした（税抜）。

  • フリープラン：0円 / 月300分（5時間）/ 1回60分まで / 保管1年・学習利用あり
  • ソロプラン：年額契約で月1,440円（月額契約は1,600円）/ 月600分（10時間）/ AI要約12回・月

つまり「無料で議事録を作りたい個人の受け皿」は、後継サービスの中に残っています。月2万円のチームプランしか見ずに「代わりが無くなった」と判断すると、選択肢をひとつ丸ごと落とすことになります。

なお、CLOVA Note β 自体は公式サイトの告知どおり 2025年7月31日をもって終了しており、いま公式トップにアクセスすると AiNote への案内だけが表示されます。復活を待つ状況ではありません。

数字だけ見ると無料枠は AiNote フリーの300分が最も大きく、Notta フリーの2.5倍です。にもかかわらず用途によって答えが割れるのは、無料プランで「消される機能」が両者で違うからです。ここが選び分けの核心なので、順番に見ていきます。

AiNote フリープラン — CLOVA Note の使い勝手に一番近い

旧CLOVA Note の正式版という位置づけなので、操作の感覚がそのまま引き継がれています。m4a・mp3・wav などの音声ファイルをアップロードするだけで文字起こしされ、対面の会議でも話者分離が働きます（公式によると最大30名まで）。対応言語は日本語・英語・中国語（簡体字/繁体字）・韓国語の5言語です。

無料のままで使う場合に確認しておきたい点は、次の4つです。

  • 「AI要約」と「Web会議の録音」の可否が公式の料金表に明記されていない。ソロプラン以上には「AI要約 12回/ドメイン」のように回数が書かれているのに、フリープランの欄はアイコン表示だけで文言が無い。使えない可能性が高いが断定はできないので、この2つが目的なら申し込み前に公式ページで確認してほしい
  • データ保管期間が1年（それ以前のノートは残らない前提で運用する必要がある）
  • 1回あたりの録音は60分まで
  • フリープランでは、録音した音声データがAI技術の性能向上に利用される場合があることに同意する形になっている（公式のお知らせに明記あり）。社外秘の音声には向かない

「自分のスマホで打ち合わせを録って、あとでテキストを読み返す」という使い方なら、この範囲でも十分に回ります。CLOVA Note をそう使っていた人は、素直にここが後継です。

Notta フリープラン — 会議に同席させたい人はこちら

一方で Notta の無料プランは、月120分と枠は小さいものの、無料のまま Zoom・Teams・Google Meet の会議にボットとして同席させられ、AI要約も月10回まで使えます。話者識別も無料プランに含まれます。

CLOVA Note を「オンライン会議の議事録づくり」に使っていた場合、AiNote フリーはWeb会議の録音が使えるかどうかを公式表から確認できません。確実に無料で会議へ同席させたいなら、明記のある Notta 側が安全な選択です。

注意点は「1回3分」の録音制限です。アプリにその場で録らせる使い方は3分で切れるので、無料で実用になるのは別の機器で録音したファイルを取り込むか、Web会議に同席させる使い方です。この線引きはAI文字起こし無料比較｜定番が終了した今、無料で残っているのは4つでも詳しく書きました。

月120分を超えるなら、プレミアム（年間プランで月1,185円）で1,800分まで一気に広がります。週1時間の会議を全部文字にしても月240分なので、有料に上げた瞬間に上限を意識しなくてよくなる価格帯です。

選び方の判断軸は3つ

1. オンライン会議に同席させる必要があるか

ここが最初の分岐です。Zoom・Teams・Meet の議事録が目的なら、無料枠の大小に関係なく Notta 側。Notta は無料プランでの会議同席が公式に明記されているのに対し、AiNote フリーは可否が確認できないためです。

逆に、対面の打ち合わせやインタビューをICレコーダー・スマホで録っているなら、この軸は関係ありません。

2. 月の合計時間が120分を超えるか、300分を超えるか

無料で粘れる境界線は、Notta が月120分、AiNote フリーが月300分です。

  • 月120分以内 … どちらでも無料で回る。機能で選ぶ
  • 月120〜300分 … 無料で通すなら AiNote フリー一択
  • 月300分超 … 無料の選択肢は消える。Notta プレミアム（月1,185円）と AiNote ソロ（月1,440円・税抜/600分）の比較になり、時間単価では Notta が明確に上

3つ目の帯に入っている人が「無料の代わり」を探し続けるのは、時間の使い方として損です。分割アップロードの手間を毎月かけるより、千円台を払って考えるのをやめたほうが早く終わります。

3. 要約まで機械にやらせたいか

文字起こしは、テキストが出てきた時点では作業が半分しか終わっていません。1時間の会議の書き起こしは1万字を超えるので、そこから要点を拾う作業が残ります。

AiNoteで回数が明記されているのはソロプラン以上（12回/月）で、フリープランの欄には記載がありません。一方Nottaは無料プランでも月10回と明記されています。 「要約まで無料で試したい」という一点だけで選ぶなら、答えはNottaになります。

正直な短所

AiNote フリー：データ保管期間が1年なので、議事録を長期の資産として貯めていく用途には向きません。AI要約とWeb会議録音は公式の料金表で無料の可否が読み取れず、「録って読む」以上のことを確実にやりたいなら結局ソロプラン以上を見ることになります。録音データが学習に利用される場合がある点も、扱う音声によっては判断材料になります。

Notta フリー：月120分は、会議を毎週文字にする人には確実に足りません。「1回3分」の録音制限も、知らずに使い始めると必ずつまずくポイントです。日本語の精度は高いほうですが、社名や専門用語は誤変換されるので、そのまま配れる議事録にはなりません。

乗り換え全般：CLOVA Note で作った過去のノートを、新しいサービスへそのまま引き継ぐ公式の移行機能は確認できませんでした。終了からすでに1年以上経っているため、過去データはあるものとして計算しないのが安全です。

よくある質問

Q. CLOVA Note はもう使えないのですか？ はい。公式サイトの告知どおり、CLOVA Note β は2025年7月31日でサービスを終了しています。現在は後継の LINE WORKS AiNote への案内が表示される状態です。

Q. AiNote は個人でも無料で使えますか？ 使えます。公式の料金表に0円のフリープラン（月300分・1回60分）が個人向けとして掲載されています。データ保管は1年で、録音データがAIの性能向上に利用される場合があることに同意する形になっています。法人向けのチームプラン（月19,800円・税抜）しか無い、というのは誤りです。

Q. 無料のまま、どこまで実用になりますか？ 「月に数回、1回30〜60分の打ち合わせを録音して、あとで読み返す」までなら無料で完結します。週次の定例をすべて文字にする、要約まで自動化する、複数人で議事録を共有して貯めていく、のいずれかが入った時点で有料プランの検討に移ったほうが、結果的に手間もお金も少なく済みます。無料で使えるツールの全体像はAI文字起こし無料比較｜定番が終了した今、無料で残っているのは4つにまとめています。
