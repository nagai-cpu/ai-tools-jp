AI記事作成の商用利用と著作権｜公式規約に書いてある注意点を読み比べた

2026-09-09 公開

この記事にはアフィリエイト広告（PR）を含みます。無料プランで実際に試した範囲の内容で、報酬額で順位を変えることはしていません。

結論から言うと、AI記事作成ツールの「商用利用OK」には、規約の条文で保証されているものと、よくある質問で説明されているだけのものがあります。Catchyは利用規約の条文で「出力テキストの著作権は当社からユーザーに移転する」と書き、Value AI Writer byGMO は規約ではなくFAQで「そのままブログ記事として活用していただくのは問題ありません」と説明しています。どちらも、公開前のチェックと結果の責任は利用者側に置かれています。

2社の公式規約に実際に書いてあること

2026年9月9日時点で各社の公式ページに載っている文言を、条番号と原文のまま並べます。

商用利用の根拠が置かれている場所利用規約の条文よくある質問。「ベースとなる『ChatGPT』はコンテンツポリシーと利用規約に従っていれば、商用利用OKと明記されております」
公開前のチェックコンテンツポリシー「必ずファクトチェック…を行い、正しく編集した状態で利用してください」利用規約 第19条「必ずファクトチェック…及び第三者の著作権を侵害いていないかのチェックを行い」（原文ママ）
責任の所在第16条2項。第三者からのクレーム等は、当社の責めに帰すべき事由がある場合を除き責任を負わない第11条「利用者が作成した記事やその内容、発信行為に対して一切の責任を負う」
出力が他人とかぶる可能性第9条6項。他のユーザーの出力と「同一又は類似となる可能性があることをあらかじめ承諾する」FAQ「完全に同じ記事になる可能性は極めて低いです」

同じ「商用利用できるAIライティングツール」でも、利用者が持ち帰れる権利の書かれ方がここまで違います。機能や料金の比較はAI記事作成ツール比較｜日本語6つの料金と無料枠を公式表記のまま並べたにまとめたので、この記事では規約だけを扱います。

「著作権が移転する」と書いてある側

Catchy の利用規約 第9条3項は、出力テキストの著作権が提供日時点でユーザーに移転すると定めています。第27条（翻案権等）と第28条（二次的著作物の利用に関する原著作者の権利）を含むと明記されており、書き直して使う前提の条文です。ただし同条4項で、ユーザーは「当社が本サービスの機能及び使用感の向上・改善の目的の範囲内で利用すること」を許諾し、著作者人格権を行使しないことにも同意しています。権利は受け取るが、サービス改善のための利用は認める組み合わせです。

「FAQで説明している」側

Value AI Writer は、利用規約を第1条から第19条まで読んでも、生成記事の著作権が誰に帰属するかを定めた条文が見当たりませんでした。第9条2項の「本サービスに関する知的財産権その他の権利を取得するものでないことを承諾します」は、サービス（システム）側の権利についての条文です。同規約 第18条が「本規約等に定めのない事項は、会員規約の規定に従う」としているためVALUE-DOMAIN会員規約も見ましたが、そちらにも帰属を定めた条項は見つけられませんでした。

代わりに、公式トップページのよくある質問にこう書かれています。「生成された文章を、公開前にご自身でチェックいただくことを前提で、Value AI Writerで生成した記事をそのままブログ記事として活用していただくのは問題ありません」「※投稿するコンテンツの責任は投稿者に帰属します」。

つまり利用者が確認できるのは、条文としての保証ではなく運営の説明です。そのまま使えるという回答が公式に出ている点は重要ですが、根拠の強さは前者と同じではありません。

規約を読んで初めて気づいた条項

料金表や機能比較には出てこないのに、使い方を左右する条項が3つありました。

「人間が独自に創作したと説明してはならない」（Catchy 第21条12号）。禁止行為として「出力テキストを、ユーザーまたは第三者その他機械ではない人間が独自に創作したものであると説明、掲載、表現等する行為」が挙げられています。AI生成であることの開示を求める条項ではありませんが、「これは私が一から書きました」と言い切る使い方は規約上の禁止行為に当たる書き方です。クライアントに納品する場面ほど効いてきます。

自動化ツールでの利用禁止（両社）。Catchyのコンテンツポリシーと Value AI Writer 利用規約 第19条4項に、ほぼ同じ文言で「RPAなどの自動化ツール、抽出ツールを用いて（本サービスを）使用することは許可されていません」とあります。量産をスクリプトで回す発想は、両社とも規約の外側です。

再販売の扱い（Value AI Writer 第12条9号）。禁止行為に「本サービスを利用して、当社の許諾を得ないで本サービスと同様のサービス…を提供する行為、又は再販売する行為」が挙げられています。自分のメディアに使うのと、記事作成そのものを商品として売るのとでは規約上の位置づけが分かれる可能性があり、ライティングを受注する立場なら契約前に運営へ確認しておく価値があります。

法律の側はどこまで整理されているか

文化庁の「AIと著作権について」のページには、「生成AIと著作権の関係に関する判例及び裁判例の蓄積がないという現状を踏まえて」考え方を整理した、と書かれています。まとめられたのが「AIと著作権に関する考え方について」（令和6年3月15日、文化審議会 著作権分科会 法制度小委員会）で、解説資料として「AIと著作権に関するチェックリスト＆ガイダンス」（令和6年7月31日）も公開されています。

条文も見ておくと、著作権法 第2条1項1号は著作物を「思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するもの」と定義しています（e-Gov法令検索）。

個別のケースでどう扱われるかは法律の専門家の領域です。この記事でできるのは公式に読める文言を並べるところまでで、判断が要る場面では弁護士など専門家に相談してください。

判断軸は3つ

1. 誰の名前で世に出すのか

自分のブログに自分の記事として出すのか、他人に納品するのかで見るべき条項が変わります。納品するなら Catchy 第21条12号と Value AI Writer 第12条9号が直接効いてきます。自分のメディアだけで完結するなら、ここは気にせず使えます。書けない時期をどう埋めるかはブログ記事が書けない・続かない｜無料枠で何回やり直せるか数えたに書きました。

2. 出力をそのまま出すのか、書き直すのか

両社とも公開前のファクトチェックを利用者の義務として規約に書き、Value AI Writer 側は著作権侵害の有無のチェックまで求めています。「そのまま出せる」と「そのまま出してよい」は別で、規約は後者を無条件には認めていません。書き直す前提でワークフローを組むほうが、規約とも実務とも噛み合います。

3. 短い文面か、長い記事か

広告コピーやLPの短文なら Catchy、SEO記事の骨組みなら Value AI Writer と設計が違います。クレジットの消費感はCatchy無料クレジット10で何ができる？記事1本でほぼ使い切る、広告文の作り方は広告コピーが思いつかない｜案出しを止めないための手順にまとめています。

正直な短所

Catchy……利用規約末尾の改定履歴は2023年3月23日が最後で、第18条2項には外部システムとして「Amazon Web Services、GPT-3、DeepL等」の名前が残ったままです。現在どのモデルで動いているかは規約の文言からは読み取れません。同条は損害賠償の上限を「本サービスの利用料金の3か月分」（消費者契約法上の消費者である場合は1万円）としています。

Value AI Writer byGMO……生成物の著作権の帰属を定めた条文が規約に見当たらず、根拠がFAQにとどまります。しかもFAQの根拠は「ベースとなる『ChatGPT』は…商用利用OKと明記されております」という基盤モデル側の規約を引く形で、そちらが変われば説明の前提も変わります。事業として大きく依存するなら、書面での確認を取っておくほうが安全です。

よくある質問

Q. 無料プランで作った記事も商用で使えますか。 両社ともコンテンツポリシーの適用を「無料、有料プランに関わらず」と書いています。商用利用の可否をプランで区別する記述は、どちらの規約にも見当たりませんでした。

Q. AIで書いたと明示する義務はありますか。 今回読んだ2社の規約に、AI生成であることの表示を求める条項は見つけられませんでした。ただし Catchy には逆方向の条項があり、第21条12号で「機械ではない人間が独自に創作したものであると説明、掲載、表現等する行為」を禁止しています。表示義務ではなく偽らない義務が書かれている、という整理になります。

Q. 生成された文章が他人の記事と似ていた場合、誰の責任になりますか。 規約上は利用者側です。Value AI Writer 第11条は「利用者が作成した記事やその内容、発信行為に対して一切の責任を負う」とし、Catchy 第16条2項も、当社の責めに帰すべき事由がある場合を除き第三者からのクレーム等に責任を負わないとしています。両社が公開前のチェックを規約本文で求めているのはこのためです。

まとめ

  • Catchyは第9条3項で出力の著作権がユーザーに移転すると明記、Value AI Writer は条文ではなくFAQで「そのまま活用して問題ない」と説明。根拠の置き場所が違う
  • 公開前のファクトチェックと結果の責任は、どちらでも利用者側。そのまま公開してよい前提の規約にはなっていない
  • 納品や再販売が絡むなら Catchy 第21条12号と Value AI Writer 第12条9号を先に読む。個別の可否判断は専門家に相談する
